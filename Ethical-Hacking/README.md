# Ethical Hacking Labs

Welcome to my hands-on penetration testing lab repository.

This project showcases my practical cybersecurity training in a controlled lab environment where I simulate real-world attack scenarios against intentionally vulnerable systems. The purpose of this repository is to demonstrate not only technical skills, but also structured methodology, documentation, and professional reporting practices used in ethical hacking and penetration testing.

---

## Project Objectives

Through these labs, I focus on developing and demonstrating:

- Practical penetration testing and ethical hacking skills  
- Vulnerability enumeration and exploitation techniques  
- Linux command-line proficiency and system navigation  
- Network scanning, service discovery, and analysis  
- Critical thinking in attack paths and exploitation strategy  
- Clear, structured documentation and reporting  

---

## Lab Environment

All testing is performed in a fully isolated virtual lab to ensure safety and ethical compliance.

- **Hypervisor:** Oracle VirtualBox  
- **Attacker Machine:** Kali Linux  
- **Target Machines:** Intentionally vulnerable systems (Metasploitable, OWASP BWA, etc.)  
- **Network Type:** Host-Only Network (isolated environment)  

---

## Methodology

Each lab follows a structured penetration testing workflow:

1. Reconnaissance  
2. Enumeration  
3. Exploitation  
4. Post-Exploitation  
5. Documentation
