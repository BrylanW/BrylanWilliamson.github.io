# Hocking Phishing Awareness Program (HPAP)

## Overview

This project demonstrates the design of a phishing awareness and simulation program for a college environment. The goal is to reduce user risk by improving behavior through training and testing.

## Problem

Phishing attacks are one of the most common ways attackers gain access to systems. Many users trust messages based on appearance and urgency, which increases risk.

## Solution

This project includes:

* A phishing awareness training module
* A phishing simulation plan
* A reporting workflow to improve response

## Key Concepts

* Social engineering and phishing tactics
* User behavior analysis
* Risk reduction through awareness

## Outcome

This program focuses on helping users:

* Recognize phishing attempts
* Make safer decisions
* Report suspicious activity

## Tools & Skills Demonstrated

* Cybersecurity fundamentals (Security+ concepts)
* Risk analysis
* User-focused security design
* Communication of technical concepts

## Future Improvements

* Automate phishing simulations using Python
* Track user behavior metrics over time
* Integrate GPT-based phishing detection

## Project Artifacts
- Phishing awareness training module

## Why This Matters
Phishing remains one of the most common ways attackers gain access to user accounts.  
This project focuses on reducing that risk through awareness, realistic simulation, and clear reporting actions.
