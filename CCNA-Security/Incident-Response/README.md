# Incident Response & Threat Mitigation

## Overview
This module focuses on incident response and threat mitigation using structured cybersecurity frameworks. The labs and reports in this section demonstrate the ability to detect, analyze, contain, and recover from simulated cyber incidents.

This work is based on the NIST SP 800-61 Incident Response lifecycle and applies real-world scenarios such as brute-force attacks and data exfiltration attempts.

##  Simulated Incident Scenario

- Incident Type: Unauthorized RDP brute-force attack  
- Indicators:
  - Multiple failed login attempts (Event ID 4625)
  - Suspicious IP address identified (e.g., 10.10.20.45)  
- Threat Activity:
  - Attempted unauthorized access  
  - Potential data exfiltration

##  Incident Response Actions

### Detection & Analysis
- Identified repeated failed login attempts  
- Correlated logs to detect suspicious activity  

### Containment
- Disabled compromised user accounts  
- Blocked malicious IP addresses using firewall rules  

### Eradication
- Removed unauthorized access vectors  
- Ensured no persistence mechanisms remained  

### Recovery
- Restored affected systems and services  
- Re-enabled legitimate user access  

### Lessons Learned
- Strengthen monitoring and alerting  
- Improve access controls  
- Enhance incident response procedures
