# Access Control & Network Monitoring

## Overview
This module focuses on securing network access and identifying potential threats through traffic analysis. The work in this section demonstrates hands-on experience configuring secure remote access and detecting common attack patterns in network environments.

---

##  Labs & Artifacts

###  Lab 3 — Secure Remote Access (SSH)
- Configured SSHv2 on network devices
- Generated RSA keys for encryption
- Created local user authentication
- Disabled insecure Telnet access
- Verified encrypted communication

 [View Lab](./SSHRemoteAccess_Williamson.pdf)

---

###  Lab 4 — Network Monitoring & Threat Detection
- Captured and analyzed live traffic using Wireshark
- Identified:
  - ICMP ping sweeps (network scanning)
  - TCP SYN port scans
  - DoS-like ICMP flood activity
- Applied filters to isolate suspicious traffic patterns

 [View Lab](./NetworkMonitoring_and_ThreatDetectionLab_Williamson.pdf)

- Documented findings from traffic analysis

- Identified all detected activity as true positives
- Mapped findings to defensive recommendations
