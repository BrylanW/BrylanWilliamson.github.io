# Documentation

This folder contains the core documentation for the Hocking Phishing Awareness Program (HPAP).

These documents outline the design, planning, and structure of the program, including training content, phishing simulation planning, and presentation materials.

Contents include:
- Phishing Simulation Plan
- Training Module materials
- Slide-by-slide presentation plan

These files represent the foundation of the program and explain how the system is designed to improve cybersecurity awareness and reduce phishing risk across campus.
