# Python Labs

This folder contains hands-on Python labs completed as part of my Python Essentials coursework and self-study.

Each lab focuses on applying core programming concepts through practical exercises and small scripts. The goal is to build a strong foundation in Python while developing problem-solving and coding skills.

---

## Objectives

These labs are designed to reinforce:

- Core Python fundamentals (variables, loops, conditionals, functions)
- Problem-solving and logical thinking
- Writing clean and readable code
- Debugging and testing basic scripts
- Applying concepts in practical scenarios

---

## Lab Structure

Each lab includes:

- A Python script (`.py`)
- A specific concept or problem focus
- Hands-on implementation of learned material

Labs are organized sequentially to reflect learning progression from basic to more advanced topics.

- Building small interactive scripts (e.g., calculator)
