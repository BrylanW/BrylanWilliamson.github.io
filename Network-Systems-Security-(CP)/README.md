# Hocking Phishing Awareness Program (HPAP)

## Overview
This project was developed as part of the CYBR-2600 Cyber Security & Network Practicum course at Hocking College. It focuses on designing a phishing awareness and simulation program to reduce cybersecurity risk by improving user behavior through training and simulated testing.

## Problem
Phishing attacks are one of the most common ways attackers gain access to systems. Many users trust messages based on appearance and urgency, which increases the risk of account compromise and data exposure.

## Solution
This project includes:
- A phishing awareness training module
- A phishing simulation plan
- A reporting workflow to improve user response

## Key Concepts
- Social engineering and phishing tactics
- User behavior and decision-making
- Risk reduction through awareness and training

## Outcome
This program is designed to help users:
- Recognize phishing attempts
- Make safer decisions when interacting with messages
- Report suspicious activity correctly

## Tools & Skills Demonstrated
- Cybersecurity fundamentals (Security+ concepts)
- Risk analysis and threat awareness
- User-focused security design
- Communication of technical concepts

## Project Artifacts
- Phishing awareness training module (slides + speaker notes)
- Phishing simulation plan
- Reporting workflow documentation
- Intrusion log analysis notes

## Metrics & Measurement
The program evaluates user behavior using:
- Click rate (users who click phishing links)
- Report rate (users who report suspicious messages)
- Submission rate (users who enter sensitive information)

These metrics help measure risk and improve future training efforts.

## Ethical Considerations
The phishing simulation is designed to be safe and educational:
- No real credentials or personal data are collected
- Users are informed after the simulation
- The focus is on learning and improvement, not punishment

## My Contribution

## Why This Matters
Phishing remains one of the most common cybersecurity threats. This project focuses on reducing that risk by helping users recognize attacks, respond appropriately, and develop safer habits.
